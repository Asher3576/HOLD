# 클로드 디자인 프롬프트 (v2 — 크롬 확장 포함)

아래 전문을 클로드 디자인에 붙여넣는다.

---

HOLD라는 투자 서비스의 UI를 만들어줘. 하나의 인터랙티브 페이지 안에 두 개의 표면을 탭으로 나눠서 보여줘: **[웹앱]** 과 **[크롬 확장]**. 확장은 실제 확장이 아니라, 가짜 차트 사이트 화면 위에 우리 오버레이가 얹힌 모습을 시뮬레이션해줘.

## 제품 한 줄

수익률 대신 "계획대로 가고 있는지"만 보여주는 결정 레이어. 실거래 미지원. 캐릭터 "홀디"가 사용자의 계획을 지켜주는 수호자다.

## 절대 규칙 (위반 금지)

1. 수익률 숫자(%, 원)는 금고 안을 제외하고 어디에도 노출하지 않는다. 대신 진행률(계획 구간 내 위치)만.
2. AI 문구는 사실과 조건문만: "65,200 저항 3번째 테스트, 거래량 감소 — 이탈 시 다음 지지 63,800" 같은 톤. "사세요/파세요/진입하세요" 같은 지시어는 절대 쓰지 않는다.
3. 홀디는 절대 실망하거나 비난하지 않는다. 표정은 평온·놀람·보호(눈가림)·보고·축하·졸림 6종만.
4. 손절선 작동은 실패가 아니라 "보험이 일한 것"으로 표현한다.

## 팔레트

배경 #EDEAE3 · 카드 #FAF8F3 · 텍스트 #1C1B18 · 딥그린(주색·홀디) #1F5F5B · 알 크림 #F2E8D8 · 경고 #B4544A · 정보 블루 #3E6491. 전체적으로 따뜻하고 부드러운 곡선, 둥근 모서리, 귀여운 게이미피케이션 톤.

## 홀디 캐릭터

SVG로 직접 그린 둥근 몸통의 수호자(작은 새/병아리 느낌). 딥그린 몸에 크림색 배. 표정 6종을 상황에 따라 전환. 부드러운 idle 애니메이션(숨쉬기, 눈 깜빡임).

## [웹앱] 탭 — 모바일 폭(480px) 기준 4개 화면 전환

**1. 홈**
- 상단: 홀디(평온) + 인사 한 줄.
- 금고: 다이얼 달린 금고 카드. 탭하면 다이얼이 돌아가며 열림 — 열리는 시간 = 1.5초 + (오늘 열람 회차 × 0.4초). "오늘 3번째 열람이에요" 표시. 열리면 계좌 요약(여기서만 금액 노출).
- 알 선반: 계획 5개가 알로 진열.
  - 삼성전자 — 품는 중, 진행률 62%, 알이 살짝 흔들림
  - SK하이닉스 — 진행률 85%인데 숫자가 블러 처리, 홀디가 눈을 가리며 "익절선 근처예요. 계획을 믿어요"
  - NAVER — 야생알(회색, 계획 미설정): "계획을 붙여주세요"
  - 카카오 — 만기 도달: "재계약할까요, 완주로 마칠까요?" 선택 버튼 2개
  - LG에너지솔루션 — 손절선 작동: 방패 배지 "보험이 일했어요"

**2. 알 만들기**
- 4개 필드: 손절선(%), 익절선(%), 기간(일), 이유(텍스트 — 비어 있으면 생성 버튼 비활성).
- 생성하면 홀디가 알을 품는 애니메이션과 함께 선반에 추가.

**3. 매도 개입**
- "팔고 싶어요" 버튼을 누르면 홀디(놀람) 등장 → 카드: "당신의 과거 매도 12건 중 8건은 판 자리에서 30일 뒤 가격이 더 올랐어요. 반대였던 4건도 함께 보여드릴게요." 12건 리스트(종목·날짜·30일 후 방향 — 상승/하락만, 수익률 숫자 없이).
- 선택지 2개: "그래도 팔게요"(기록됨) / "참을게요" → 참으면 열매 획득 토스트 + 홀디 축하.

**4. 도감**
- 부화(완주) 알 컬렉션, 방패(보험 작동) 배지, 열매(참은 기록 — 채점되면 익은 색으로 변함) 그리드.

## [크롬 확장] 탭 — 데스크톱 폭, 가짜 차트 사이트 시뮬레이션

배경에 그럴듯한 캔들 차트 화면을 목업으로 그려줘 (심볼 "TSLA", Y축 가격 라벨 포함, 다크 톤 — 남의 사이트라는 느낌). 그 위에 우리 레이어:

**a. 확장 팝업** — 우측 상단에 작은 팝업: 홀디 얼굴 + "이 차트에 홀디 부르기" 버튼. 누르면 아래 b~e가 순서대로 나타나는 데모 시퀀스.

**b. 지지/저항 오버레이** — 차트 위에 딥그린 지지선 2개, 경고색 저항선 1개(점선). 각 선 끝에 라벨: "지지 228.4 · 3번 터치 · 강함". 선이 그려질 때 왼쪽에서 오른쪽으로 슥 그어지는 애니메이션.

**c. AI 애널리스트 브리핑 카드** — 차트 옆에 카드: "241.0 저항 3번째 테스트 중, 거래량은 감소. 이탈 시 다음 지지 228.4. (지연시세 기준)" — 사실·조건문 톤 그대로.

**d. 손익비 코치** — 오버레이에 드래그 핸들 3개(진입·손절·목표). 드래그하면 실시간 계산 카드: "손익비 1 : 2.3 · ADX 31 추세장, 방향 일치 · 당신의 TSLA 상승 적중률 34% (12건 중 4건)". 하단에 딥그린 버튼 "이대로 알 만들기 →" (웹앱으로 이어지는 퍼널).
- 손익비가 1 미만이 되게 핸들을 옮기면 카드 테두리가 경고색으로 바뀌고 홀디가 놀란 표정: "잃을 폭이 벌 폭보다 커요" (그래도 지시는 하지 않음).

**e. 홀디 현장 개입** — 화면 구석에 작은 홀디: 이 종목이 내 알이면 등장. 진행률이 익절 근처면 눈을 가리는 포즈. 말풍선: "오늘 이 차트 14번째예요 :)" (비난 없는 톤, 확인 중독 미터).

## 목데이터

- 웹앱 알 5개는 위 명세 그대로.
- 과거 매도 12건: 8건은 30일 후 상승(참았어야), 4건은 하락(팔길 잘함) — 방향만 표시.
- 확장 차트: TSLA, 현재가 235.6, 지지 228.4/221.0, 저항 241.0, 진입 235.6/손절 228.0/목표 253.0 → 손익비 2.3.

## 기술

단일 React 컴포넌트, 외부 이미지 없이 SVG/CSS만. 탭 전환과 위 인터랙션(금고 다이얼, 블러, 오버레이 애니메이션, 핸들 드래그, 열매 토스트)이 실제로 동작해야 해.
