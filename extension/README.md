# @hold/extension — 크롬 확장 (사이드 패널)

보고 있는 주식 페이지 옆에 HOLD를 띄운다 — 실시세·지지/저항·손익비·작도.

## 빌드 & 설치

```bash
pnpm --filter @hold/extension build   # → extension/dist/
```

1. `chrome://extensions` → 개발자 모드 ON
2. "압축해제된 확장 프로그램을 로드" → `extension/dist` 선택
3. 주식 페이지(네이버 증권·트레이딩뷰 등)에서 툴바의 HOLD 아이콘 클릭 → 우측 사이드 패널

## 기능

- **종목 자동 인식**: URL 어댑터(네이버 증권 PC/모바일, 트레이딩뷰, 토스증권) + 수동 입력
- **실시세**: HOLD `prices` 엣지 함수(KIS) — 확장에 API 키 없음, CORS 로 직접 조회
- **지지/저항**: 최근 일봉 90개의 스윙 피벗 → 1% 클러스터 (결정적 계산, LLM 없음)
- **차트에 긋기**: 레벨/진입·손절·목표를 페이지 차트 위 오버레이로 —
  최초 1회 2점 보정(①현재가 위치 클릭 ②눈금 클릭+가격 입력). 차트를 움직이면 다시 긋는다
- **작도**: 수평선(클릭)·추세선(드래그) — 보정 불필요, ESC 종료
- **손익비 계산**: 진입/손절/목표 → 1:N + 사실 문장 ("잃을 폭이 벌 폭보다 커요")

## 설계 원칙

- 상시 주입 없음 — 아이콘을 누른 탭에서만 (`activeTab`)
- DOM 스크래핑·스크린샷 저장 없음 — 화면 좌표만
- 지시어 없음 — 사실·조건문만 (`@hold/shared` compliance 정책과 동일)
