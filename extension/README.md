# @hold/extension — 크롬 확장

보고 있는 차트 위에 홀디를 부르는 확장 (Manifest V3).

## 개발

```bash
pnpm --filter @hold/extension build   # → extension/dist/
```

1. `chrome://extensions` → 개발자 모드 ON
2. "압축해제된 확장 프로그램을 로드" → `extension/dist` 선택
3. 아무 차트 페이지에서 툴바의 홀디 아이콘 → "이 차트에 홀디 부르기"

## 설계 원칙

- **상시 주입 없음**: `activeTab` — 사용자가 부른 탭에서만, 그 순간에만 동작.
- **DOM 스크래핑 없음**: 차트는 캔버스라 어차피 못 읽는다. 화면 좌표(오버레이)와
  스크린샷(캘리브레이션)만 다룬다.
- **스크린샷 즉시 폐기**: 서버는 축 라벨 좌표만 뽑고 원본은 저장하지 않는다.
- **심볼 인식 1순위는 URL/타이틀 파싱**(사이트 어댑터), 비전은 폴백.
